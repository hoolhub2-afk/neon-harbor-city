Neon Harbor is a 3D open-world crime game in the spirit of GTA 6: explore a neon harbor city on foot and by car, steal cars, outrun the police as your wanted level rises, and run a 5-mission story chain — playable in desktop Chrome, no network needed.

## Run it

```sh
node serve.ts
# then open http://localhost:8080 in desktop Chrome
```
